# 📊 Personal Finance & Budget Analytics Tracker

## 📝 Project Overview
The **Budget Analytics Tracker** is a data-driven financial project designed to monitor, categorize, and analyze monthly income against various expenditure streams. By mapping granular transaction data (e.g., rent, groceries, shopping) to macro-financial goals, this project provides a clear picture of cash flow, burn rate, and goal variance.
This project demonstrates the ability to clean raw transactional data, track Key Performance Indicators (KPIs), and calculate budget utilization percentages to drive smarter financial decision-making.

## 🎯 Key Features
* **Automated Categorization:** Maps individual micro-transactions (e.g., Dominos, Clubbing, Footwear) to macro-categories (Food & Drinks, Travel, Shopping).
* **Goal Variance Tracking:** Compares `Actual` spend vs `Goal` allocation using percentage benchmarks.
* **Cash Flow Analysis:** Tracks the exact breakdown of the ₹31,979 monthly expenses against the baseline income.

## 📈 Key Insights & Findings
1. **High Discretionary Spending:** A significant portion of the budget is heavily skewed towards Shopping (46% of budget utilized) and Travel (50% utilized). 
2. **Fixed Cost Constraints:** Utilities (Rent) operate at a high 75% utilization rate, leaving less room for financial maneuvering.
3. **Savings Scaling:** The current savings rate represents only 3.33% of the ultimate financial goal, highlighting the need for either expense optimization or income scaling to hit the long-term target.
